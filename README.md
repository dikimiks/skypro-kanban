# Skypro Kanban

Веб-приложение на Vue 3 для ведения списка задач в формате канбан-доски. Интерфейс работает с API курса `wedev-api.sky.pro`; для входа и работы с задачами требуется подключение к серверу.

## Возможности

- Регистрация и вход по электронной почте и паролю.
- Доступ к доске только после авторизации.
- Создание задач с названием, описанием, категорией и сроком из календаря.
- Просмотр задачи, редактирование описания, статуса и срока, удаление.
- Перемещение задач между колонками доски.
- Темная тема интерфейса.
- Загрузка задач с индикацией ожидания, сообщением об ошибке и возможностью повторить запрос.
- Страница 404 со ссылкой на главную.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки выполните:

```sh
npm run build
```

Изображения и favicon размещены в `public/`.
