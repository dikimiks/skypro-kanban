# Skypro Kanban

Веб-приложение для ведения списка задач в формате Kanban-доски. Пользователь может войти или зарегистрироваться, создавать задачи и управлять ими через доску.

## Технологии

- Vue 3 и JavaScript
- Vue Router
- Vite
- REST API `https://wedev-api.sky.pro/api`

## Установка и запуск

Требуются Node.js 18 или новее и npm.

```sh
npm install
npm run dev
```

После запуска откройте адрес, указанный Vite в терминале.

Для production-сборки выполните:

```sh
npm run build
```

## Реализованные функции

- Регистрация и вход через API; данные авторизованной сессии сохраняются в браузере.
- Защита страниц доски и перенаправление гостя на страницу входа.
- Просмотр задач на доске с пятью статусами, перемещение между статусами перетаскиванием.
- Создание, редактирование и удаление задач через API.
- Указание категории, описания и даты выполнения задачи; выбор даты в календаре.
- Состояния загрузки, сообщения об ошибках и повторная загрузка списка задач.
- Переключение светлой и тёмной темы с сохранением выбора.
- Страницы выхода из аккаунта и 404 для неизвестного маршрута.
